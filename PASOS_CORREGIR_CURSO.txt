OPCIÓN A: ELIMINAR EL CURSO (RECOMENDADO) ✅

───────────────────────────────────────────────────────────────

OPCIÓN B: CORREGIR MANUALMENTE

  1. Haz clic en el nodo del curso
  2. Haz clic en "Agregar campo" o edita directamente
  3. Agrega estos campos:

     title: "Nombre del Curso"          (REQUERIDO)
     type: "curso"                      (Opcional)
     meta: "Descripción"                (Opcional)
     files: []                          (Opcional)
     code: "TU_CODIGO_AQUI"             (Opcional)
     card: {}                           (Opcional)
     createdAt: 1733175000000            (Opcional)
     updatedAt: 1733175000000            (Opcional)

  4. Haz clic en "Guardar" o presiona Enter
  5. ✅ LISTO

═══════════════════════════════════════════════════════════════
  PASO 5: VERIFICAR
═══════════════════════════════════════════════════════════════

1. Abre la aplicación en tu navegador
2. Presiona F12 para abrir DevTools
3. Ve a la pestaña "Console"
4. Pega y ejecuta este código:

   const hex = '2291db02a1c676fcb2f5effd7bba8232c1d7eb75ab236f4880aa8ce0536359c0';
   const merged = App.getMergedAccessHashMap();
   const course = merged[hex];
   console.log('Curso:', course);
   console.log('Es válido:', !!(
       course &&
       typeof course === 'object' &&
       Object.keys(course).length > 0 &&
       course.title &&
       typeof course.title === 'string' &&
       course.title.trim().length > 0
   ));

5. Si eliminaste: Debería mostrar "Curso: undefined" ✅
6. Si corregiste: Debería mostrar el objeto con datos y "Es válido: true" ✅
